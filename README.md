# 星甲娱乐（GF-plugin-xjyl）

咔咔珂（Kakake）QQ 官方机器人娱乐插件，3.0 模块化版本。

## 功能

副本 / BOSS / 天下楼 / 转生 / 强化 / 探索 / 挖矿 / 打工 / 钓鱼 / 做菜 / 赌场 / 转盘 / 抽卡 / 银行 / 商店 / 交易行 / 装备升级与转移 / 联盟 / 排行榜 / 音乐点歌 / B 站解析 / 超能力 / 时空门 / 新手指引 / 每日任务 / 群管 / 网页控制台；战斗自动用药。

- 详细使用说明：[使用指南.md](使用指南.md)
- 完整功能文档：[插件文档.md](插件文档.md)
- 更新记录：[插件文档.md](插件文档.md) 内的更新公告，或 GitHub Releases 页面

## 安装

1. 从 Releases 下载 `GF-plugin-xjyl-vX.Y.Z.zip`，解压得到插件目录。
2. 将整个 `GF-plugin-xjyl` 目录放入咔咔珂的 `plugins/` 下。
3. 在控制台插件列表打开总开关即可加载。

## 网页控制台

插件启用后，控制台插件列表中点击「打开控制台」。首次登录默认密码见使用指南，登录后请尽快修改。
